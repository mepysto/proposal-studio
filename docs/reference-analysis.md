# SmartFence 디자인 레퍼런스 검토

폴더에 3종보다 많은 자료가 있어 아래 세 PDF를 먼저 선정했습니다. 모두 디자인 참고이며 사업내용의 근거로 사용하지 않았습니다.

1. AI스마트도시정보시스템제안서(에스엘티)_천안: 13페이지. 네이비 대제목, 큰 여백, 도시·장비 상징. 한글 CID 매핑이 부족해 Poppler 미리보기의 일부 문구가 누락됨을 확인했습니다. 분석 가능한 폰트에는 NotoSansKR·TmonMonsoriBlack 등이 있습니다.
2. (강민코퍼레이션) Edge-AI 및 디지털트윈 기반 능동형 산업안전 통합관제 시스템 개발: 20페이지. 큰 한글 제목과 산업 현장 이미지의 좌우 분할, 절제된 파란 강조색, 선명한 정보 위계. 강조된 성능 문구는 SmartFence 성능 근거로 전용하지 않았습니다.
3. (시장님보고용) 제천_의림지뜰_순환형_태양광_치유길_제안서: 7페이지. 크림색 바탕, 딥그린, 넓은 여백, 공간 예상도와 좌측 메시지 결합. 이미지 기반으로 텍스트·폰트 추출이 불가능해 렌더링 이미지를 확인했습니다.

각 자료의 첫 2페이지 이미지를 생성하고, 텍스트·폰트·색·페이지 크기를 추출했습니다. 비교한 핵심 표지 3장을 시각 확인했습니다. 전체 페이지 디자인을 모두 검토하거나 자동으로 고급 디자인 시스템을 역설계한 것으로 표시하지 않습니다. 상세 추출 데이터는 해당 프로젝트의 materials.json과 cache에 보관됩니다.

새 디자인은 cream/petrol teal 계열, 단일 한글 폰트, 편집 가능한 프로세스·동선 도형으로 재구성했습니다. 사진·로고·인포그래픽은 원본에서 재사용하지 않았고 표지 개념도만 새로 생성했습니다. 시제품 전 장을 1600px PNG로 확인했습니다.

## 추가 사용자 레퍼런스 — 보행접근로 실증 자료

2026-10-27 추가 제공된 16페이지 자료는 [선택적 참고 검토](reference-walkway-review.md)에 기록했다. 사용자는 이 디자인을 선호 템플릿으로 지정하지 않았다. 사건별 작동 확인, 전체 장면에서 장비 상세로의 단계화, 보류·연장 조건은 참고하되 반복 카드·작은 글씨·빈 이미지 영역·정적 PDF에 남은 UI 제어는 따라 하지 않는다. 원문의 사업 수치와 정책·인증 주장은 검증된 SmartFence 근거로 편입하지 않았다.
