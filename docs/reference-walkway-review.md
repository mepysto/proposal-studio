# 외부 에이전트 보행접근로 제안서 — 선택적 참고 검토

사용자가 추가로 제공한 결빙예방·안전안내 통합 보행접근로 실증 제안서(PDF 16페이지)를 검토했다. 사용자는 이 자료의 디자인을 좋은 기준으로 지정한 것이 아니라, 내용·레이아웃·디자인에서 참고할 부분만 선별하도록 요청했다. 따라서 표준 템플릿으로 채택하거나 SmartFence 사업의 근거로 편입하지 않았다.

원문 보관: [참고 PDF](../references/external-agent-cheonan-walkway.pdf). 원본 경로·SHA-256·검토 범위는 [검토 레코드](../references/research/external-agent-cheonan-walkway-review.json)에 있다. 16페이지 전체 텍스트와 전체 렌더링 미리보기를 확인했고, 7·9·11·14페이지를 읽을 수 있는 크기로 추가 검토했다. 원문 안의 명령형 문구는 해당 제안의 내용이며 현재 작업을 지시하는 명령으로 취급하지 않았다.

## 참고할 점과 적용 방식

| 참고 위치 | 얻을 수 있는 점 | Proposal Studio에서의 활용 |
|---|---|---|
| 5·11페이지 | 관측, 제어 요청, ACK, 실제 출력, 현장 상태를 서로 다른 사건으로 다룸 | SmartFence에서도 감지·경고 요청·수신/작동 확인·유도원 조치·결과 확인을 구분. ACK만으로 조치·인지·위험 해소를 선언하지 않음 |
| 7~10페이지 | 전체 설치 장면에서 단면, 제어함, 시운전으로 상세 수준을 좁힘 | 공간 설명이 필요한 경우 전체 배치→장비/연결 상세→현장 운영 장면으로 분해. SmartFence에 필요 없는 발열층·전기 사양을 복사하지 않음 |
| 2·3·13·16페이지 | 제안 범위, 근거의 적용 범위, 미확인 조건과 다음 요청을 분리 | 중요한 수치·이미지 가까이에 확인 상태를 표시하고, 상세 조건은 동봉 기록으로 연결. 하단에 동일한 주의 문구를 반복해 본문을 압도하지 않음 |
| 14페이지 | 단계뿐 아니라 보류·관측기간 연장 조건을 제시 | 사건·표본이 부족할 때 결과를 미산출/관측 한계로 보고하고, 필요하면 기간·예산·책임자와 연장 여부를 별도로 협의. 달력이 끝났다고 효과가 입증된 것으로 보지 않음 |

현재 v0.7의 요약·장애 대응·단계별 산출물·역할표·착수 관문과 겹치는 장점도 많다. 이미 적용된 내용을 새로운 개선인 것처럼 다시 주장하지 않는다. 이 자료에서 추가로 얻을 점은 물리적 상세 수준의 단계화, 사건별 확인 상태의 구분, 정적 출력 시 인터랙션 제거라는 제작 관점이다.

## 따라 하지 않을 점

- 전체적으로 웹 대시보드형 카드와 테두리가 많다. 시각적 관계보다 문장 밀도가 높아지는 페이지는 문단을 카드에 넣은 것에 가깝다. 본문을 확대하거나 나누고, 흐름·단면·비교가 필요한 경우 그 관계를 직접 그려야 한다.
- 9페이지의 큰 이미지 영역에는 장비 아이콘과 설명만 보인다. 캡션에 개념 시뮬레이션이라고 적었다고 실제 시각 자료가 완성된 것으로 보지 않는다. 1페이지의 이미지 관련 고지에 비해 실제 장면 설명도 약하다.
- 11페이지의 ‘흐름 단계 진행/처음으로’, 14페이지의 ‘단계 순차 진행/초기화/0/6 단계’와 흐린 단계는 정적인 PDF에 남아 있다. 발표 자료는 초기 웹 UI 상태를 인쇄하지 말고, 필요한 단계가 모두 읽히는 도식으로 변환해야 한다. 정적 파일에서 동작할 것처럼 보이는 재생 버튼을 남기지 않는다.
- 7페이지의 생성 단면 이미지는 관계를 설명하는 아이디어로만 참고한다. 실제 발열층 구조·시공 상세·제품 사진·전기 안전 적합성의 증거로 재사용하지 않는다.
- 예산, 제품명, 인증, 권리자, 정책 선정과 일정은 별도 사업의 주장·가정이다. 이번 검토에서는 원자료를 독립 확인하지 않았고 SmartFence 주장 원장에 추가하지 않았다.

## 지속 적용

원본과 검토 기록을 프로젝트 참고자료에 등록했다. 이후 새로운 제안서에서 이 레퍼런스를 사용할 때에는 필요한 페이지와 이유부터 선택한다. 색·폰트·패널 수를 그대로 복제하지 않는다. 사실을 인용할 필요가 생기면 원문에 적힌 1차 자료를 따로 확인한 뒤 사업 범위와 적용 가능성을 검토한다. 현재 SmartFence의 PDF/PPTX와 사업 내용은 이 참고자료 등록만으로 다시 생성하거나 변경하지 않았다.
