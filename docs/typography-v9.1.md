# 페이지별 타이포그래피 설계

사용자 요청에 따라 전체 25페이지에 개별 핵심 문구를 작성했다. 공통 읽기 위계는 제목 32pt → 둥근 배경 안 핵심 메시지 21pt → 본문·중요 라벨 16~24pt → 보조 조건·출처다. 표지와 첫 문제 페이지에는 별도 크기·폭을 적용했다.

단순히 문장 전체를 같은 회색으로 확대하지 않고, 핵심 메시지 안의 지정 어구와 본문 도식의 중요한 대상·행동·조건을 편집 가능한 부분 볼드/색상으로 강조했다. 제안/작동 원리는 청록, 후보지/정보 구분은 파랑, 위험과 우선 확인은 황토 계열을 쓴다. 의미는 색상에만 의존하지 않고 문구와 굵기로 함께 구분한다.

공통 설명 색은 기존보다 진하게 조정했다. 보조 설명은 실제 너비·높이 안에서 16pt로 확대하고, 좁은 조건 설명은 본문 핵심과 구분한다. 숫자 배지와 기존 기능 블록도 둥근 모서리와 내부 정렬을 유지한다. 지도·장비 이미지는 비율과 피사체를 보존한다. 표지 다음 페이지는 문제 제기를 유지하며 이미지 아래 설명 띠는 추가하지 않는다.

`visualPlan.readingGuide`에 메시지/핵심 어구/본문 강조 어구/톤을 저장하고, 검토된 제작 레시피가 재적용한다. 런타임 LLM·API 호출 없이 실행된다. 실제 PPTX의 텍스트·볼드·색상·둥근 도형과 출력 결과를 함께 확인한다. 자동 검사는 전문적인 시각 판단이나 독립 승인 점수가 아니다.
