# 에스엘티 중심 통합 제품과 구매 가치의 시각화

사용자의 최신 정정에 따라 관제 제품의 대외 명칭은 ‘AI 지능형 안전 관제’다. 에스엘티가 제안하고 AI 제품 역량을 가진 기술참여 기업이 함께 구성하는 통합 제품으로 소개한다. 제조·개발 이력은 출처 원장에 보존하되 각 회사명을 제품 브랜드처럼 나열하지 않는다. 표지·마지막·본문의 제안 주관은 (주)에스엘티로 유지하고 기술참여 기업은 기존 협력 표기에 남긴다.

## 11페이지: 같은 기준의 비교와 구매 이유

기존의 Axis 기능 소개와 Samsung 기능 소개를 따로 나열하는 방식을 폐기했다. ‘위험 인식 / 안내·표출 / 운영·재사용’ 행에 두 공개 제품 구성과 에스엘티 통합 제안을 나란히 놓는다. 제안 열은 청록 배경·테두리와 구체적 장점으로 구분한다. 장점은 현장 조건에 맞춘 안전 구성, 안전·공공정보의 복합 활용, 공급 뒤의 운영·회수까지 같은 제안 범위로 구성하는 것이다. 유일 기능이나 비교시험으로 입증된 성능 우위로 주장하지 않는다.

Axis 공식 문서의 사람·차량 분석과 이벤트·경광/사이렌 연계, Samsung XHB-F 공식 사양의 옥외 표시·디밍을 기준으로 사용한다. 공개되지 않은 통합·회수 기능이 없다고 표시하지 않으며 제안/구성별 확인 대상으로 둔다. Samsung의 모듈 상태 모니터링 기능이 공개돼 있다는 점도 고려해 ‘모니터링 없음’으로 표현하지 않았다. 동일 완제품 세트·가격·실제 천안 입찰사 비교로 표시하지 않는다. 공식 문서 2026-10-28 재열람: https://help.axis.com/en-us/axis-object-analytics 및 https://image-us.samsung.com/SamsungUS/samsungbusiness/displays/direct-view-led/xhb-series/xhb-f-outdoor/XHB-F-Outdoor-Leaflet.pdf.

## 14페이지: 전광판 제품 화면

검은 장비 베젤·내측 화면·모서리 체결 표시, CCTV 채널명, 두 보행자 인식 박스, 출차 대기와 유도원 통제·운전자 직접 확인 표시, 안전 경고 띠와 후순위 공공정보 영역을 편집 가능한 PPTX 요소로 구성한다. 원본 CCTV 개념 장면의 비율을 그대로 맞추고 동일 좌표 변환으로 객체 박스를 배치한다. 객체 위치·숫자는 설명용 장면에 붙인 시각 주석이며 실제 AI 탐지 결과나 정확도 수치가 아니다. 통제 중 표시도 현장 확인·실동작 증명의 대체물이 아니다. 미검출과 확인 불가 상태의 별도 설명을 유지한다.

## 19페이지와 설명 그룹

시민 안전(접근 음성·주의), 현장 대응(LED·직접 확인·유도원), 천안시 활용(공공안내·광고와 회수/재투입)을 각 이미지와 메커니즘·가치로 연결한다. 이미지 비율은 유지하고 보호할 피사체를 자르지 않는다. 기존 두 제품 장면은 앞선 기능 설명을 가치로 연결하는 명시적 이유로 재사용한다. 새 공공정보 장면은 내장 image_gen으로 생성해 `examples/assets/public-information-value-v11.png`에 저장했고 프롬프트·출처·개념 상태는 `examples/assets/provenance-v11.json`에 남겼다. 실제 천안 설치 사진이나 지리적 경관의 증거로 사용하지 않는다.

화살표는 각 카드의 중앙에 배치한다. 설명은 흰색 라운드 테두리, 소제목과 결과는 부드러운 색 배경으로 묶는다. 제품 역량·정보 흐름·도입 범위·운영서비스·시연 비교·확산·추진안에도 관련 그룹 단위의 배경과 테두리·내부 여백을 적용한다. 측정하지 않은 사고 감소율·경제성 수치는 추가하지 않았다.

## 재현 계약

`refine-integrated-presentation.ts`가 이전 레시피 뒤에서 최신 정정을 적용한다. `comparisonMatrix`, `productStrategy.driverScreen`, `municipalCase.benefitScenes`에 콘텐츠와 시각 앵커를 구조화했다. 실제 비교 행, 인식 표시·통제 상태, 가치 이미지를 렌더링 QA에서 검사한다. 인식 표시의 원본 좌표와 PPTX 좌표 일치는 테스트하며, 원본을 벗어난 좌표는 제품 기획 QA에서 막는다. 자동 검사는 심미성 승인이나 독립 전문가 검토가 아니다.
