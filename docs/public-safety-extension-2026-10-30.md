# 공공안전 공간 확장과 CCTV 구성 비교

사용자는 공사장 외 공공안전 장소에 대한 기획과 기존 CCTV 차별화 장표 추가를 요청했다. 기존 공사장 실증을 핵심으로 유지하고 23장의 시연 판단 뒤에 두 장을 추가했다. 전체는 27장, 추진 제안과 제안사 연락처는 26/27장이다. 이전에 제거한 수요 미확정 지역 사업기회 장표를 복원한 것은 아니다.

## 비교 근거와 제품 경계

2026-10-30 Axis 공식 영상 분석, Camera Station action rules/integration, sound detection 자료를 확인했다. 지능형 CCTV 생태계도 객체/이벤트 분석, 음성·경보와 관제 연동을 지원한다. 그러므로 ‘기존 CCTV는 녹화만 가능’이나 ‘AI·음성·관제는 본 제품만 가능’ 같은 주장은 채택하지 않았다. 제안의 차별성은 구매·운영 범위와 장소별 현장 안내 구성에 두고, 성능 우열·독점·최저가·입증된 사고 감소를 주장하지 않는다.

- 공식 기능 안내: https://help.axis.com/en-us/axis-camera-station-feature-guide
- 영상 분석: https://www.axis.com/products/video-analytics
- 오디오 연동: https://www.axis.com/solutions/sound-detection
- 근거/확인 과제: `references/research/public-safety-cctv-2026-10-30.json`

기존 카메라의 영상 접근·코덱·해상도·지연·망/권한·촬영 범위·장착 여건은 사전 검증한다. 새 시설 유형은 설치 수요나 검증 완료 제품 기능을 의미하지 않는다. 침수/범죄 예측, 군중 압사 판단 등 확인되지 않은 분석 기능을 추가하지 않았다. 물리적 차단과 현장 책임을 유지하며 공간별 설정과 기능 시험을 제안한다.

## 이미지와 공개 대상

내장 imagegen으로 3개 공간의 동일한 장치/표출/현장 대응이 보이는 장면을 제작했다. 최초 생성 화면에 공개 CCTV 영상이 섞여 있어 채택하지 않고, 화면 부분을 안전 기호·방향 안내로 교체했다. 최종 자산은 공개 안내 장면이며 원본 생성·수정 이력과 프롬프트를 기록했다. 실제 천안 현장·설치 제품·검증 사진이 아니다. 이미지에 생성 방식 배너를 붙이지 않고 적용 개념이라는 해석 한계를 유지한다. 내부 운전자 화면의 객체 인식 예시는 기존 14장에 별도로 남긴다.

## 구현과 검수

`businessCase.publicSafety`에 비교·적용 유형·위험·반응·검수 조건·근거를 구조화했다. `extend-public-safety.ts`가 두 장을 중복 없이 추가하며, `public-safety-composition.ts`는 편집 가능한 비교와 흐름/설명 및 비율을 보존한 공간 이미지를 렌더링한다. `visual-evidence.json`에도 확장 계약을 보존한다. 지침/현재 사례의 페이지 수와 CCTV 비교 원칙을 갱신했다.
