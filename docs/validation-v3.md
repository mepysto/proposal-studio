## 렌더링 검토와 수정

25개 PNG를 5개씩 묶어 전 장을 확인했고, 최종 예산 페이지는 원본 크기로 다시 확인했다. 첫 실행에서 표지 줄바꿈과 후보지 관계도·설명 상자의 겹침을 발견해 수정했다. 공공디자인 장표의 이미지 옆 설명 간격을 조정했고, 예산 장표에는 별도 비용을 직접 표시했다.

표지·설치·공공디자인 이미지는 실제 천안 현장 사진이 아닌 생성 개념도로 표시했다. 후보지 관계도는 실제 지도처럼 좌표나 거리를 부여하지 않았다. 지역 소개·후보지·설계·책임·비용·효과·측정·중단 기준의 연결과 수치 가정 표시를 확인했다.

자동 검사는 실제 사업 필요성이나 안전 효과의 증명이 아니다. PowerPoint 데스크톱 앱에서의 편집·발표 재현은 별도로 수행하지 않았다. 외부 전문 검토·견적·실사·시험·관계부서 검토는 미완료이며 `finalApproval`은 false로 유지된다.

## 핵심 수치의 범위

- 예산: 공급가 기준 4,500만/7,200만/1억800만원. 기획 시나리오이며 확정 견적이나 천안시 편성 예산이 아니다. VAT 10% 가정 시 기준 7,920만원. 같은 모델에서 표·차트·합계를 계산한다.
- 시간 절감: 20건×20일×(5−2)분÷60=20시간/월. 모든 입력이 가정인 산식 예시다. 성과·목표·인건비 절감·사고 감소로 제시하지 않는다.
- 성과 지표의 기준선·목표: 모두 미측정·미확정(null). 현장 시험 후 합의할 조건이다.
- 후보지: 천안역세권·오룡지구·봉명지구 모두 not-surveyed. 공개 사업의 존재·주소와 실제 설치 가능성을 구분한다.
