# 페이지별 시각 검토와 연락처 장표

검토 기준은 프로젝트 시각 스토리텔링, 설치된 Presentations의 시각 디자인/기존 자료 편집 지침, professional-drawio의 시각 검토·연결선 품질 지침이다. 현재 대화의 작성자가 해당 관점을 적용해 실제 1600px 전체 페이지 출력을 읽으며 검토했다. 독립 디자이너나 복수 외부 전문가의 승인을 받은 것이 아니다. 내용 근거와 지리/정량 자료는 그대로 유지했다.

새 로고는 제공 PDF의 로고 영역을 직접 렌더링해 추출했다. 이미지 편집 모델로 재해석하거나 로고를 새로 그리지 않았다. 원본의 전화 숫자가 텍스트 추출에서 누락돼 원본 페이지 렌더와 직접 대조해 전사했다. `(041) 571-2057/8` 표기를 보존하고 이메일은 `slt888@hanmail.net`, 본사는 `충남 천안시 동남구 청당산업길 143(구룡동)`을 사용한다. 외부 최신성 확인을 했다고 표시하지 않는다. 마지막 장에서는 전화/이메일/주소 각각의 라벨·아이콘·큰 본문을 같은 패널 기준에 배치하고, 회사 로고 비율을 그대로 유지한다.

`proposer.contact`와 `append-proposer-contact.ts`가 연락처 근거·추가 페이지를 보존한다. 반복 제작 시 연락처 페이지가 중복되지 않으며 원래 25페이지와 기존 5/7페이지 예제는 별도로 유지된다. 연락처 장표는 요청된 정체성/연락 목적에 맞춰 실제 로고와 읽을 수 있는 법인명·전화·이메일을 검사한다. 본문 장표의 시각자료 커버리지 정책을 낮추지 않는다.
