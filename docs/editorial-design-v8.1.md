# 제목·가독성·정렬 개선 설계

사용자 요청: ~니다로 끝나는 페이지 제목을 없애고, 글자 크기·배경 블록·레이아웃·아이콘·블록 내부 정렬을 개선.

- 제목은 각 페이지의 실제 주제와 판단 대상을 짧게 명명. 단순히 어미만 잘라내지 않고 전면 재작성. 본문과 음성 예시의 자연스러운 문장은 유지.
- 본문 페이지 공통 제목 32pt, 설명 17pt. 고정 왼쪽 기준과 짧은 구분선으로 위계 설정. 첫 문제 페이지는 이미지·문제 우선 구조 유지.
- 번호 배지의 텍스트를 실제 박스에 가로·세로 중앙 정렬. 반복 둥근 패널을 평면 행·구분선 중심으로 변경. 상태·처리 범위 등 의미를 가진 배경은 유지.
- 제품·LED 설명의 수신자/의미/조치를 13~18pt로 구분, 항목 간 여백과 구분선 확보. 지도 측면 설명은 14pt로 확대.
- KPI 페이지는 카드 테두리를 제거하고 동일 폭의 열린 비교 구성으로 변경. Lucide 아이콘은 기능 구분에만 사용.
- 현장 선정표와 소유·운영 비교표의 셀 세로 정렬 통일. 역할표의 긴 협력 주체는 열 너비를 넘지 않게 줄 분리. 비교 이미지 테두리는 실제 맞춤 이미지 크기에 맞춤.

제목은 `scripts/refine-editorial-design.ts`에 보존해 입력 재생성 시 재적용. `technical-editorial-v2` 출력 QA에 서술형 제목 검사를 추가. 과거 5/7장 예제의 스타일 계약은 변경하지 않음. 이미지 비율, 제품 기능, 주관사, 근거와 견적 미확정 조건은 유지.
