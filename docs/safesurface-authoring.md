# SafeSurface Cheonan authoring

Audience: 천안시 담당자와의 초기 협의. 원문 `examples/Cheonan_SafeSurface_AI.md`에서 시작한 별도 제안서로, 현재 30장이다. SmartFence 프로젝트는 변경하지 않았다.

- 편집 입력: `projects/safesurface-cheonan/project.json`
- 검토 예제: `examples/safesurface-cheonan.project.json`
- 재생성: `npm run studio -- run --project safesurface-cheonan`
- 기초 작성: `scripts/create-safesurface-cheonan.py`; 기존 입력 교체에는 명시적인 `--overwrite` 필요. 마지막에 `scripts/refine-safesurface-buyer.py`를 호출한다. 두 스크립트는 검토된 사례 작성법이며 자율 연구/전문가 엔진이 아니다.
- 구형 26장 입력: `projects/safesurface-cheonan/revisions/v1-technical-26-pages.project.json`. 후속 기술 협의용 상세는 `supporting-technical-content.json`에 보관하고 본문에서 분리했다.
- 전용 렌더러: `safesurface-composition.ts`, `safesurface-buyer-composition.ts`. 네이티브 텍스트·도형·연결선·비누적 비용 차트는 PowerPoint에서 편집 가능하다.

## 구성과 근거

2–8쪽은 필수 접근로·재결빙·그늘/배수/경사·시민 영향·관리 업무와 적용 우선순위, 10쪽은 도로면 융설에서 출발한 적용 맥락, 11–21쪽은 ECO WAY의 필름 발열 원리와 EcowayVision의 실제 문서상 기능을 구체화했다. 이후에는 운영 예시·기대 변화·실증 범위·후보지·일정·SLT 역할·다음 협의·연락처만 남겼다.

사용자가 첨부한 `FEATURES (1).md`와 `EcowayVision_User_Manual.md`를 직접 읽고 변경 없이 `references/research/`에 복사했다. 기능 문서의 구현 기재는 실행/성능 시험을 통과했다는 뜻이 아니다. 코드·실행 환경을 검증하지 않았다. 매뉴얼이 참조하는 screenshots 파일은 제공되지 않아 관제 화면은 명시적으로 매뉴얼 기반 재구성 화면과 예시 데이터로 표시했다. 수동제어 권한·인터록, 네 가지 운전 상태와 보호정지 분기, 실제 출력/노면 확인, 경보 담당 배정/해결과 기록을 구분했다. 중앙 통신 장애 시 독립 제어 등 미완료 기능을 완료로 주장하지 않았다.

제조사 ECO WAY·3D나노히터·적용 사례 공개 자료를 대화에서 확인했다. 필름 기반 스노우멜팅과 열 전달을 설명한다. 11쪽에는 사용자 요청에 따라 제조사 제시 최대 90% 소비에너지 절감을 상대지수 기존 100 대비 약 10으로 환산해 표시했다. 정격전력 10%나 천안 실측 성과로 전용하지 않는다. 공개 표의 단위·시험조건은 추가 확인 대상이며 인증/시험 완료를 주장하지 않는다. 제공 개발 의뢰서는 요구/목표 자료로 읽었으며 완료 성능 증거로 사용하지 않았다. 출처·해시·범위는 `references/research/safesurface-v2-source-review.json`에 있다.

천안시 제설자원 기사 R1은 2차 보도이며 시설별 수요의 증거가 아니다. 사용자 요청에 따라 비용 페이지와 본문/발표자 노트의 금액·요금·비용 설명은 제외했다. 원문 예산 모델은 이전 입력 및 내부 자료에 보관하며 제출용 PPT/PDF에 표시하지 않는다. 운영비·현장 추가 공사·권리·절감 성과는 미확정이다. 후보지와 면적은 현장 조사 가정이다.

## 시각 자료와 검토

내장 이미지 생성으로 만든 장면은 설치 개념·결빙 문제·필름 열 전달 설명용이며 실측 현장 사진이나 확정 시공 단면이 아니다. 이미지 생성 출처·전체 프롬프트·선택 파일·해시·한계는 assets/provenance.json과 v2-generation-prompts.json 및 출력 사본에 보관했다. 원본 SLT 로고와 확인된 연락처만 사용했다.

CLI는 오프라인 컴파일만 수행하며 API 키·외부 모델 API를 사용하지 않는다. 대화 중 출처 확인과 내장 이미지 생성은 CLI 연구 수행으로 표시하지 않는다. 실제 PPTX→LibreOffice PDF→PNG 30쪽을 개별 확인했고 마지막 수정 네 쪽을 재검토했다. 자세한 페이지별 관찰은 `docs/safesurface-page-review.md`와 output/page-review.json에 있다. 자동 검사 통과는 전문 품질 승인과 다르며 finalApproval은 false다. Microsoft PowerPoint 앱에서 검사했다고 주장하지 않는다.

## v3 연결선 수정

`connector-anchors.ts`는 최종 상자 경계에서 좌우/상하 포트를 계산한다. SafeSurface 전용 렌더러에서 단계 중심·반환선·보호 버스·회신 포트를 수정했다. production.md에는 연결 대상/방향/경계 접합/중심/레이블 간격을 렌더링 후 전수 확인하도록 명시했다. economicsPresentation은 비용 제외가 명시된 사례만 지원하고 기본 필수 장 검사는 유지한다. 최종 30장 전수 검사 기록은 page-review.json 참조.

## 표지 역할 표기

현재 표지는 `(주)에스엘티`, 아래 한 줄은 `기술협력 (주)나노일렉트로닉스`로 표시한다. 주관·제품사라는 표시를 표지에 추가하지 않는다. ECO WAY 제품 귀속과 SLT 통합 제안 역할의 근거는 구조화된 출처에 보관한다. 실제 계약·독점권을 뜻하지 않는다. 표지 수정 후 검사했으며 2–30쪽은 v4와 픽셀 동일하다.

## 11쪽 차별성 설명

나노기술·저전력 스노우멜팅을 먼저 제시하고, 필름 개념 옆에 제조사 최대 절감 조건의 상대 소비에너지 비교를 네이티브 차트로 표시한다. 근거는 ecoway-energy claim 및 ecoway-relative-energy dataset, 출처 상세는 references/research/ecoway-energy-claim-2026-10-29.json. 정격 소비전력 420W/120W의 비율을 10%로 설명하지 않는다. 천안 현장 성과는 별도 검증한다.

## v7 관제 설명 개편

15–21쪽은 기능 목록·사용자 지침 위주에서 관제 화면과 현장 판단 사례로 바꿨다. 대시보드, 현장 상세, AI 타임라인, 경보 관리, 정비의 다섯 화면은 제공된 매뉴얼/기능명세에 근거한 재구성이며 실제 캡처가 아니다. 시설 A/B/C·계측값·시각·조치·사용전력량은 설명용 가상 사례다. 실제 기능에 없는 화면을 완성된 제품 증거로 주장하지 않는다.

`refine-safesurface-interface.py`는 기본 buyer recipe 마지막에 적용된다. VisualPlan.interfaceExample에 출처 주장·예시 값·담당자의 판단과 대응을 보관하고, visual-evidence.json에도 그대로 내보낸다. 신규 safesurface-interface-composition.ts는 이를 네이티브 PPT 도형/텍스트로 렌더링한다. 원본 화면 스타일의 복제나 실제 프로그램 구현을 뜻하지 않는다. 문서의 이미지 상대 경로는 공급되지 않았으며 references/research/safesurface-interface-source-review.json에 실제 확인 범위를 기록했다.

나머지 문제·물리 제품·경고·실증·다음 협의 페이지는 독자 질문에 맞는 장면/비교/의사결정을 설명하고 있어 유지했다. 생산 스킬에는 단순 모듈명 상자를 대시보드로 제시하지 말고, 정보·상태·시각과 구매 담당자의 판단을 함께 보여주도록 보강했다.

## v8 페이지별 개별 장면

2·4쪽의 반복 이미지 문제를 수정했다. 4쪽은 그늘·융설수·배수구·경사가 함께 보이는 높은 시점, 13쪽은 반대편 설치 범위, 16쪽은 높은 관제 전경, 17쪽은 노면·센서·배수구 근접 장면으로 각각 별도 제작했다. 2쪽 및 표지의 기존 이미지는 유지한다. 모든 설명 장면/재구성 영상 영역은 파일 내용 기준으로 중복이 없으며 원본 SLT 로고는 예외다. 장면별 주석을 새 이미지의 실제 대상에 맞게 조정했다.

내장 이미지 생성만 사용했고 API 키·외부 모델 API는 사용하지 않았다. 전체 프롬프트와 생성 원본 경로는 assets/v8-generation-prompts.json, 해시와 페이지 사용처는 assets/provenance.json에 보관한다. 새 이미지도 실사·실제 CCTV·설치 완료의 증거가 아니다. 작성 스킬에 유사 사례라도 같은 장면을 반복/재크롭하지 않고 별도 장면을 제작하도록 명시했다. 회귀 검사는 모든 장면과 인터페이스 이미지의 실제 파일 내용 중복을 확인한다.

## v9 전체 검토와 의미 정합성

30장을 새로 읽고 개별 렌더링을 검토했다. 9쪽은 관측→위험 추정/예열→가열 요청과 역방향 출력 확인, 안내→담당자 현장 조치→재관측의 실제 관계로 수정했다. 18쪽은 예보 발행시각과 강설 예상시각을 구분하고 추정 입력·판단 사유를 명시했다. 19쪽은 위험 해소 후 정지 복귀를 추가하고 대표 흐름임을 표시했다. 21쪽의 A-01 예시 온도를 -2.1℃로 맞추고 단일 저온보다 승온 추세와 현장 점검을 대조하도록 했다. 28쪽에는 Nano 기술협력을 명시하고 SW/시공 참여범위와 구분했다. 7쪽 과거 자료, 27쪽 제안 일정, 29쪽 공동 조사 요청을 명확히 했다.

최종 전체 검사는 93개 중 90통과·3조건부 건너뜀·실패0. 비용 본문/노트 제외, 7개 개별 장면, 표지 회사명·원본 연락처, 실제 문서 렌더링을 확인했다. 부지·소프트웨어 권리/실물 연계·시험조건·성과는 후속 확인 대상이며 실제 준비 완료로 주장하지 않는다.
