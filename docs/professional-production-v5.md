# v0.5 전문 도식·제안 주체·사전 조판 기준

## 문제와 변경

v0.4는 시각 자료의 존재를 검사했지만, 선 몇 개로 그린 사람·트럭·장비가 반복돼 제안서에 필요한 표현 수준에 미치지 못했다. 회사명도 수행 역할에 작게 들어 있어 제안 주체가 드러나지 않았다. 시각 자료의 면적과 오류 개수는 디자인 품질의 대리 지표가 될 수 없다.

이번에는 이전 픽토그램 제작 함수를 교체하고, 라이선스가 기록된 Lucide SVG와 공통 조판 키트, 선언된 관계를 배치하는 ELK 엔진을 적용했다. 물리적 공간은 새로 생성한 입체 모델과 편집 가능한 경로·주석으로 설명한다. 시스템·운영 도식은 현장 영역, 사람의 실제 대응, 기록의 흐름을 구분한다. 문서의 분량과 지역 근거는 유지했다.

## 제안 주체

제공 원문 `examples/Cheonan_SmartFence_AI.md`의 작성자·역할 표가 근거다.

- 제안 주관: **(주)에스엘티**
- 기술 협력: **강민코퍼레이션·비트리**

`project.proposer`에 법인 표기, 역할, 협력사, 원문 주장 ID를 저장한다. 표지에는 제안 주관을 큰 글자로, 협력사를 별도 역할로 표시한다. 본문 공통 표기·제안 범위·수행 체계·마지막 요청과 PPTX 작성자/회사 속성에도 연결한다. 실제 계약·조달·안전 운영 권한은 확정된 것으로 표시하지 않는다. 로고·연락처·인증은 만들어 넣지 않는다.

## 사전 레이아웃 설계

- 제목·본문·설명·출처의 계층을 구분하고 본문은 왼쪽 정렬한다. 공통 제목 왼쪽 기준은 약 0.64인치다.
- 이미지와 텍스트를 넣기 전에 실제 장면의 비율과 보호할 대상, 주석 앵커, 옆 설명의 폭을 정한다. 장면·장비 이미지에는 contain을 사용해 의미가 있는 대상을 자르지 않는다.
- 프레임은 실제 맞춰 넣은 이미지에 맞춘다. 과도한 빈 테두리와 이미지/본문 사이의 불필요한 간격을 줄인다.
- 수행 주체의 열 폭·간격과 회사명 기준선을 맞추고, 제안 주관을 색과 역할 표기로 구분한다.
- 현장 처리·운영 기록·후속 협의의 경계, 시스템·사람의 책임과 처리/기록 경로를 분리한다. 아이콘만 바꾼 동일 상자를 모든 주제에 적용하지 않는다.
- 측정하지 않은 성능을 게이지·진행률·과장된 감지 범위로 표현하지 않는다. 공간 모델은 실제 천안 배치도나 시공 완료 사진으로 사용하지 않는다.

## 설치·적용한 도구

설치/출처/버전/적용 범위는 `production-toolchain.json`에 기록했다.

| 도구 | 실제 적용 |
|---|---|
| 외부 Draw.io 스킬 2.8.0 | 오프라인 도식 규칙, 연결·정렬·검토 지침, 시스템 관계의 편집 가능한 원본 생성·검증 |
| lucide-static 1.61.0 | 수작업 픽토그램을 대체하는 ISC 벡터 심벌 |
| elkjs 0.12.0 | 선언된 논리 노드/연결의 직교 배치 |
| 기존 Presentations·imagegen | 슬라이드 계층·전 장 검토, 입체 공간 모델 생성 |

PPTX 후보 스킬 하나는 설치 후 확인한 사용 조건이 적합하지 않아 신규 설치본을 제거했다. 해당 스킬이나 코드는 프로젝트에 복사하지 않았다. Draw.io Desktop은 설치하지 않았으며 내장 오프라인 CLI로 `.drawio`/SVG를 실제 생성했다. 별도 모델 API와 API 키는 사용하지 않았다.

`examples/diagrams/smartfence-architecture.drawio`는 시스템 관계를 편집할 수 있는 별도 원본이다. PPTX 전체가 Draw.io에서 만들어졌거나 이 파일이 슬라이드와 픽셀 단위로 동일하다는 뜻은 아니다. PPTX의 주요 도식과 텍스트는 네이티브 요소, 심벌은 SVG, 공간 장면은 비트맵이다. 공간 장면의 내부 객체는 개별 편집 대상이 아니며 주석은 편집할 수 있다.

## 재현과 지침

`npm run demo`로 25페이지를 제작한다. `npm run diagrams:source`는 설치한 외부 스킬로 시스템 관계 원본을 다시 생성한다. CLI 주 실행은 글로벌 스킬 설치 경로에 의존하지 않으며 노드 의존성은 package-lock에 고정돼 있다. 샘플 입력 생성 스크립트는 제안 주체·전문 조판·장면 자산·시각 계획을 다시 적용한다.

사용자의 이번 지시는 `AGENTS.md`와 `skills/proposal-visual-storytelling/SKILL.md`에 추가했다. 다음 프로젝트 작업에서 제안사 확인, 목적에 맞는 제작 방식, 조판 사전 계획, 이미지 비율/앵커 보호, 전 장 검토를 다시 적용한다. 전역 계정 전체의 기억을 바꿨다고 주장하지 않는다.
