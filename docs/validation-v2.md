# v0.2 실제 검증

검증일: 2026-10-27 (Asia/Seoul).

- TypeScript 검사 통과.
- 단위 테스트 24개 통과. 기본 테스트에서 통합 테스트 2개는 명시적으로 skip하며 별도 실행함.
- 실제 변환 통합 테스트 2개 통과: 구형 5장 경로의 호환성, 신형 기획 브리프의 7장 제작, 네이티브 도표 텍스트 보존, 개별 장표 재생성 시 전체 출력 보존.
- 새 예제 전체 실행에서 PDF 7페이지·PNG 7장·전체 시트를 생성. 기획 오류와 렌더링 오류 없음. 전 장의 1600px PNG를 직접 확인함.
- 기존 예제와 새 예제는 서로 다른 프로젝트 디렉터리에 보관. 원본 Markdown·레퍼런스 파일은 수정하지 않음.

새 회귀 검사는 일반 근거→지역 관측 도약, 확인 구절 없는 검증 표시, baseline 누락, 해결되지 않은 원인, 잘못된 원인·검증 ID, 문제보다 먼저 나오는 해결책, 반복 답, 근거 누락, 기획 변경 후 오래된 장표, 장표 문구·한계·레이아웃의 기획 불일치, 공간모델 누락, 잘못된 설치 이미지 번호 연결, 개념 이미지와 증거의 분리를 다룸.

웹 조사 3개 출처는 개발 중 수동 확인해 원장에 기록했으며 앱이 실시간 검색한 것이 아님. 천안 현장 수요·사고·운영 공백·성능을 확인한 것으로 표시하지 않음. 설치 개념도 2종은 내장 이미지 도구로 제작했고 앱의 이미지 API는 미연결. 주관적 미적 점수는 생성하지 않았으며 최종 승인 상태는 false로 유지함.

기획 검사는 계약과 참조 관계를 검사한다. 원인 추론의 완전성, 대안 선정의 우수성, 시장성·경제성, 모든 문장의 진실성이나 디자인의 전문가 품질을 자동 증명하지 않는다. 현재 브리프는 검토해 작성한 구조화 입력이다.
