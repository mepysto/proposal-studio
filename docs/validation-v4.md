## 시각 검토

25페이지를 4개씩 묶은 1000px 너비 장표로 확인했다. 실제 장면 이미지의 생성 결과도 직접 확인했다. 최종 운영 흐름(16), 일정(18), 시간 산식(22), 지표(23)는 1600px 원본으로 다시 확인했다.

검토 과정에서 일정·조직 설명의 텍스트 넘침과 본문/보조 라벨 겹침을 수정했다. 모호했던 경고 아이콘을 교체하고, 수직 화살표의 방향과 시스템–사람–기록의 연결을 바로잡았다. 실측이 없는 미탐률은 분자·분모 구조로 표현해 가상의 성공/실패 비율로 오해하지 않도록 했다. 작업시간 차트에는 월 시간 단위와 소수점 한 자리를 표시했다. 하단 출처는 내부 주장 ID 대신 읽을 수 있는 출처 명칭으로 바꿨다.

검사는 LibreOffice PDF 변환과 PNG를 기준으로 했다. PowerPoint 데스크톱 앱의 편집·발표 재현, 외부 전문가 승인·실사·안전 효과 시험은 수행하지 않았다. 최종 승인 플래그는 false다. 구성 영역 검사는 의미적 품질이나 실제 도형 잉크 면적의 증명이 아니므로 시각 검토와 함께 사용한다.
