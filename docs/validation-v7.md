## 작성자 출력 검토

기존 전체 미리보기와 2·19페이지를 먼저 보고 결정을 돕지 못하는 구조를 확인했다. 수정 후 2~25페이지를 읽을 수 있는 크기로 확인했다. 표지는 기존 디자인을 유지했다. 최종 축소 미리보기도 다시 작성했다. 자동 검사를 디자인 평가 점수로 사용하지 않았다.

요약의 핵심 질문 줄바꿈, 역할표의 긴 회사명, 단계 막대의 기간과 산출물, 정상/장애 경로, 보류/통과 조건, 최종 요청과 후속 판단의 분리를 확인했다. 최초 출력의 요약 질문과 역할표에서 발견된 텍스트 높이 문제를 문장과 배치로 수정했다. 한국어의 ‘위험 수요’를 관찰 대상인 ‘위험 노출/남아 있는 위험’으로 다듬었다. 도표 내용과 시각화 설계 메타데이터도 함께 수정했다.

통계 페이지에서 포괄적 정책 근거가 수치 출처보다 먼저 표시되던 문제를 고쳐, 대전일보 두 보도와 발행일을 그래프 바로 아래에 표시했다. 지역 맥락 페이지에는 기존 정책 방향과 본 사업 예산·계약의 구분을 본문에 보강했다. 출처 원장과 근거 고지를 확인했다.

## 남아 있는 실증 전제

현장 출입구·공정·보행/차량량·설치 위치는 조사 전이다. 지도는 동/주변 시설 참고점이고 개념 이미지는 생성물이다. 지역 통계는 2차 보도이며 공사장 성과가 아니다. 예산·기간·시간 산식과 새 역할/절차는 기획·협의안이다. 실제 순절감, 성능 목표, 계약과 운영 책임은 측정·견적·협의로 확정해야 한다.

외부 자격 전문가의 독립 검토, Microsoft PowerPoint 앱 검증, 현장·발주·안전 승인으로 표현하지 않는다. `finalApproval=false`를 유지한다. 자동 QA와 작성자의 출력 검토는 실제 사업 승인과 다르다.
