# 표지 다음 첫 본문(2페이지) 수정

사용자가 말한 ‘첫 번째 메인 페이지’는 표지가 아니라 그 다음 페이지였다. 이전 작업에서 표지를 대상으로 해석한 것은 오류였다. 표지는 원래의 사업/솔루션 소개 이미지와 문구로 되돌리고, 공통 이미지 비율 수정은 유지했다.

2페이지는 범위·기간·예산·솔루션을 먼저 요약하던 구성을 문제 중심 도입으로 바꿨다. 왼쪽에는 ‘공사장 출입구, 차량과 보행자의 동선이 겹칩니다’라는 제목과 동선 교차, 가려진 시야, 알림 이후 실제 조치 확인이라는 세 문제를 배치했다. 오른쪽에는 설치된 AI 장비가 없는 일반적인 출입구 문제 장면을 원본 비율로 넣었다. 이미지 설명 띠는 넣지 않았고, 생성물/일반 위험 구조라는 짧은 고지만 하단에 남겼다. 실제 천안 현장 관찰이나 사고 자료로 표현하지 않는다.

범위·일정·예산은 각각 본문의 실증 범위, 추진 일정, 예산 페이지에서 계속 확인할 수 있다. 전체 장수는 25장을 유지했다. 새 이미지의 출처·권리와 문제 설명의 근거는 메타데이터와 노트에 보존했다. `scripts/refine-decision-design.ts`와 지속 지침을 수정해 재생성할 때에도 표지와 첫 본문의 역할을 혼동하지 않도록 했다.

검증: 최종 실행 `2026-10-27T11-14-13-152Z-8716b1`, 25장 출력 QA 오류 0건. 표지와 2페이지를 읽을 수 있는 크기로 확인했고 단위 테스트 56개와 25장 통합 검사가 통과했다. 재생성 전후 JSON 동일성과 프로젝트 스킬 검사도 통과했다.
