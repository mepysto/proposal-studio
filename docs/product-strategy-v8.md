# v0.8 — 양방향 안전 안내와 현장 간 반복 활용

사용자는 기존 솔루션 이미지에 실제 제안 제품과 기능이 보이지 않는다고 지적했다. 추가 요구는 ① 차량 출차 시 보행자 음성·주의 알림 ② 공사현장 내부 대형 LED의 외부 보행도로 영상·보행자 상태 안내 ③ 공사 진행·필요 정보 동시 표출 ④ 준공 후 회수·보관·다른 현장 재투입이다. 이 문서는 그 사용자 요구와 이번 작성자의 설계를 구분해 보존한다. 기술 구현 완료·현장 실증·확정 견적·시 보관 장소 확보를 뜻하지 않는다.

## 제품과 현장 시나리오

12페이지는 현장 **안쪽**에서 기다리는 운전자가 출차 전에 볼 수 있는 내부 LED, 보도 측의 음성/주의 모듈, 촬영/제어 구성을 함께 보여준다. 첫 생성 시안은 LED 방향이 운전자용으로 명확하지 않아 제외하고, 내부 시점으로 다시 제작했다. 14페이지는 운전자 화면 설계 예시다. 위쪽은 비식별 보행 상황과 감지 상태, 아래쪽은 승인된 작업·공사정보다. 영상은 실측 CCTV가 아닌 생성 예시이며 실제 제품 UI도 확정 전이다. 17페이지는 보행자에게 보이는 스피커·경광등·주의 표시와 예시 음성 문구를 보여준다.

- 차량 접근이 감지되면 외부 보행자에게 음성·주의 알림을 전달한다. 주야간 소리 도달·인지·소음·눈부심·통행 영향을 확인한다. 반복·불필요 알림과 민원도 측정한다.
- 운전자 LED는 현장 안쪽에서 볼 수 있어야 한다. 감지영역 내 ‘보행자 감지’, ‘미검출’, ‘확인 불가’를 구분한다. 미검출은 안전·통행 허가를 뜻하지 않는다. 오래된 영상이나 장애를 정상 화면처럼 계속 보여주지 않는다. 직접 확인과 유도원 통제는 유지한다.
- 공사정보는 작업명·공정·주의 등 승인된 내용만 별도 영역에 표출한다. 안전 정보를 가리거나 운전자의 주의를 분산시키지 않도록 우선순위·밝기·가독성·갱신/만료·게시 책임자를 시험하고 합의한다. 실제 공정률이나 일정 숫자는 만들지 않았다.
- 외부 보행 영상을 불특정 다수에게 공개 재송출하는 안으로 취급하지 않는다. 내부 제한 표출에서도 촬영·표출 근거, 식별정보 보호, 접근·보존·삭제와 현장 고지를 개인정보 담당자가 검토해야 한다. 비식별화의 성능·법적 적합성을 검증한 것으로 표시하지 않는다.

기존 감지→담당자 경고 중심의 계획을 양방향 알림으로 수정했다. 13페이지 인과 경로, 후보지 설치 가설, 장애 시 복구 조건, 채널별 전달 지연·업무/민원 측정도 함께 갱신했다. 2페이지의 문제 중심 도입과 표지/본문의 구분은 유지했다.

## 반복 활용 운영 모델

21페이지는 현장 A 설치·운영→준공 후 회수→점검·보수→지정 장소 보관/다음 수요 배정→현장 B 재설치·검수의 경로다. 모듈형 LED·카메라·음성·제어 장비를 대상으로 하며, 현장 고정 토목·전기 공사까지 그대로 재사용된다고 가정하지 않는다.

자산 ID·구성·위치·운영기간·장애·수리·입출고·재설치 비용 이력을 남긴다. 회수 때에는 안전한 분리·원상복구·인계와 영상/계정 정리가 필요하다. 보관 전 고장 설비를 격리하고 사용 가능 상태를 확인한다. 재설치 때에는 이전 현장의 촬영영역·위험구역·계정·통신 설정을 초기화하고, 새로운 위치·운전자 시야·음성·LED·장치 상태를 재검수한다. 이전 현장에서의 인수 합격을 다음 현장에 그대로 승계하지 않는다.

시 관리 공간은 확보된 장소가 아니다. 소유자, 물품관리·보관 책임자, 입출고와 다음 현장의 배정 창구, 유지관리/보험·분실·손상·수리 책임을 먼저 협의한다. 다음 수요가 없으면 유휴 보관비가 발생하므로, 후보 공정 일정과 다음 활용 수요를 조사한 뒤 추가 구매/배정을 판단한다.

## 사업·비용 구조

22페이지는 **시 소유+유지관리 위탁**을 우선 협의할 수 있는 안과 **공급사 보유+임대/서비스** 대안을 같은 표로 비교한다. 특정 소유·계약 방식의 적법성이나 경제적 우위를 확정하지 않는다. 물품관리·계약 담당자의 검토와 동일 범위 견적이 필요하다.

시 소유안은 기간별 운영·점검과 실제 이전 작업의 대가를 구분하고, 임대/서비스안은 임대·운영료에 회수·이전·보관이 포함되는지 계약에서 확인한다. 기본 지원 범위, 추가 유상 작업, 고장·분실·손상과 종료 시 인수 조건을 견적서에 분리한다.

비교의 기준은 같은 LED/장비 규격, 운영기간, 현장 수, 지원 범위다. 신규 구매를 현장마다 반복하는 안과 모듈을 반복 활용하는 안의 **총비용**을 대조한다. 최초 장비비만 나눠 절감률을 계산하지 않는다. LED·프레임·전력/통신, 현장별 설치/설정, SW·콘텐츠/통신/운영, 철거·운송·원상복구, 점검·수리·소모품/재검수, 보관/관리 비용을 모두 포함해야 한다. 수명·재사용 횟수·실제 가동률·유휴기간·고장률·잔존가치가 확인되기 전에는 절감률·손익분기·투자 회수를 제시하지 않는다. 새 지표 ‘재배치·유휴·이전 비용’의 기준선과 목표는 미측정으로 두었다.

20페이지는 기존 4,500/7,200/10,800만원 범위를 **과거 축소안 참고**로만 남겼다. 이는 대형 LED·회수/재설치를 포함하지 않은 옛 기획 범위이며 현재 확장 구성의 공급가·승인액·총액이 아니다. 확장안 총액은 신규 견적 전이며 금액 필드는 null이다. 기존 금액에 LED가 포함된 것처럼 범위를 바꾸거나, 새 원가를 임의로 더하지 않았다.

## 천안시 담당자가 판단할 산출물

첫 협의는 후보 현장과 함께 발주·현장 안전·영상/정보보호·물품관리 담당 창구를 정하는 것이다. 이후 현장 배치/음성·LED 시험 조건, 게시 책임, 소유/보관/배정 구조, 신규/반복 비용 견적과 서비스·회수 조건을 묶어 제한 실증 착수를 판단한다. 시의 실제 보관 장소나 후속 현장 배정은 확인 전이다.

## 자료 확인과 한계

2026-10-27 국가법령정보센터에서 [천안시 물품 관리 조례](https://www.law.go.kr/LSW/ordinInfoP.do?ordinSeq=2118229)의 현행 표제/시행일과 물품관리 관련 자료를 탐색했다. 본문 동적 표시의 한계가 있어 이번 자료만으로 특정 보관·위탁·계약 행위가 허용된다는 법률 판단을 하지 않았다. [개인정보 포털 CCTV 안내](https://m.privacy.go.kr/front/per/chk/cctv/improveChkCctvQ2.do)의 검색 결과로 안내 항목을 확인했으나 직접 열기는 502였으므로, 이 기록을 현장 설치·영상 표출의 승인 근거로 사용하지 않는다. 적용 법령·내부 절차는 담당자가 원문과 실제 설치 조건을 재확인해야 한다.

새 제품·사업 내용의 직접 출처는 사용자 요구(U-PRODUCT)이며, 세부 장면·역할·비용 구분은 작성자의 제안 설계다. 개인정보·물품 규정을 준수한 것으로 인증하거나 새 정책 선정 사실을 주장하지 않는다. 생성 이미지·프롬프트·미채택 시안은 `examples/assets/provenance-product-v8.json`에 보존했다. API 키나 외부 모델 API 호출은 사용하지 않았다.

## 재사용 구현

`businessCase.productStrategy`가 기능/수신자/상태, 5단계 자산 운영, 소유 대안, 신규 견적 항목과 예산 개정 상태를 저장한다. `scripts/apply-product-strategy.ts`가 검토된 입력을 재적용한다. 계획 단계에서 기능의 지표 연결, 세 가지 표시 상태, 회수/보관/재설치와 비용 항목, 견적 전 null 금액을 검사한다. 실제 제품·사업 도식이 렌더링됐는지도 검사한다. 상세 정보는 `business-case.md`, `visual-evidence.json`으로 내보낸다. 25장 구성은 유지했다.
