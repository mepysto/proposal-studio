> **제안 성격:** 천안시와 현장·행정·예산 적합성을 협의하기 위한 시범사업 초안입니다. 현장별 제설 수요·발열재 시공 적합성·전력용량·특허/인증 및 EcowayVision 권리관계는 확인 전이며, 확정된 발주예산·공인 성능·안전인증을 의미하지 않습니다.

# 01. 핵심 제안: 도로 전체보다 '필수 접근로 1곳'부터

**사업명: 「천안시 AI 예측형 결빙예방·안전안내 통합 보행접근로 실증사업」**

폭설·한파에 취약한 시민이 **반드시 이용해야 하는 경사 접근로 한 곳**에 면상발열, 기후·노면 AI 관제, LED 안내와 상태확인 기능을 결합한다. 시스템의 목표는 단순한 '열선 작동'이 아니라 **위험이 남아 있을 때 그 상태를 숨기지 않고 알려주며, 위험 지속시간·에너지 사용·조치 과정을 측정하는 것**이다.

| 핵심항목 | 1차 실증 제안 |
|---|---|
| 대상 | 천안시 관리 복지·공공시설의 외부 경사로/필수 보행 접근로 **1개소** |
| 설치 범위 | 면적 **20~60㎡ 가정**; 실제 전기용량·경사·포장재 조사 후 확정 |
| 기술 구성 | 나노 ECO WAY 발열·전력제어 + EcowayVision AI 기후관제 + SLT LED/CCTV/스마트폴 |
| 신규 개발 초점 | `SLT Safety Display Bridge`: 융설/위험 상태→승인된 현장 안내문+표출 확인 |
| 사업 주체 | **천안시 시설 관리부서 1곳** 중심; 전기/포장 시공은 적격업체 별도 참여 가능 |
| 최초 일정 | 2026~27 겨울 벤치 시험 → 2027년 실시설계/설치 → 2027~28 겨울 실증(제안) |
| 직접 성과 | 결빙 위험지속시간, 실제 노면 상태 변화, 출력·전력 기록, 경고 전달 성공률 |

## 천안시에 맞는 이유

- **실제 제설 행정 수요:** 천안시는 2025년 겨울 제설제 1만t, 제설장비 45대, 인력 104명 등 비상 대응체계를 발표했고 고지대 급커브·경사도로 및 고가도로·교차로를 중점 관리 대상으로 설명했다.[R1]
- **국가정책과 일치:** 국토교통부는 2026년 2월 전국 결빙 취약지점 121곳 집중관리와 노면정보 경고·열선 등 다중 수단을 활용하는 도로 결빙 대책을 발표했다.[R2] **121곳이 천안시의 숫자는 아니다.**
- **추가 가치:** 기존 제설장비를 전부 대체하지 않고, 장비 출동 전 또는 반복 결빙이 발생하는 **짧은 접근로의 예방·안내**를 검증한다.
- **범위 관리:** 공공도로 전광표지·교통신호 제어를 처음부터 포함하지 않으므로 관련 기관의 광범위한 연계 필요성을 줄인다.

# 02. 천안의 실증 문제 정의

## 현재 확인된 것과 확인되지 않은 것

**확인된 것:** 천안시는 겨울철 제설자원과 결빙 취약도로 관리체계를 운영한다.[R1] 국가 차원에서도 결빙 위험예측·노면 정보 제공을 강화하는 중이다.[R2]

**아직 확인되지 않은 것:** 천안시 공공시설 중 특정 경사 보행로의 과거 미끄럼 사고 건수, 제설 민원 빈도, 융설설비 구축 현황, 전기 인입 여건, 해당 장소에 승인된 2027년 예산은 공개 근거가 부족하다. **대상지 선정 이전에 '천안에서 반드시 필요한 곳'이라고 특정할 수 없다.**

## 왜 ACCESS 제품을 우선하는가

지자체 도로열선 사업은 기초·매설·교통통제, 도로관리청 협의 등이 포함돼 규모가 커진다. 병원·복지시설·공공청사 입구의 국소 보행접근로는 **관리 주체가 단일한 경우** 상대적으로 적은 협의로 실증을 시작할 수 있다. 장애인 접근경로를 공사 중 유지해야 하므로 시공 단계의 통행계획이 중요하다.

1차 실증에서 차량도로용 도로전광표지, 가변속도제한표지, 자동통행차단, 시 전체 스마트도시 플랫폼 통합은 제외한다.

**명확한 미완료 항목:** 중앙 연결이 끊긴 뒤 Edge가 새 가열 결정을 독립적으로 내리는 완전 자율제어, 실제 PLC/SSR HIL, 30일 연속운전, 외부 안전시험·침투시험, 최종 SLA 증적은 사용자 제공 기능명세에서 완료로 표시되어 있지 않다.[I1]

**전력 출력 한계:** 실제 물리출력은 Modbus ON/OFF로 구현되어 있고 `power_level_pct`는 명령 메타데이터이므로 연속 비례출력 제어를 상용기능으로 주장하지 않는다.[I1]

## 제품 신설 기능: SLT Safety Display Bridge

EcowayVision은 **열·기상·위험 판단의 데이터와 제어 원장**을 유지하고, 에스엘티 측 Bridge는 다음만 수행한다.

1. 현장·가열구역별 **위험 상태 / 데이터 출처·최신성** 수신.
2. 가열 요청, ACK, 실제 출력확인, 노면 위험 개선상태를 **서로 다른 상태**로 보관.
3. 승인된 메시지 템플릿을 SignStudio/LED/현장 안내화면으로 전송.
4. 전광판 플레이어 실제 ACK·장치 상태 확인 및 로그 기록.
5. 데이터가 오래됐거나 Vision이 불확실하면 '안전해졌다'는 표현을 차단하고 주의 안내 유지.

**표시 사례**: `결빙 주의`, `노면 상태 확인 중`, `미끄럼 주의` 등의 문안. 시가 승인한 위치·용도·시인성 기준에 맞춰 현장별로 결정한다. 완전한 안전 보증 문구, 생성형 AI 자유문장, 법정 교통표지 대체 기능은 금지한다.

# 04. 시스템 동작 시나리오

**사례: 전날 눈·비 이후 새벽 재결빙 가능성이 있는 경사 보행로**

- **관측:** 현장 노면온도·수분/결빙 센서와 기상자료를 수집하고 유효기간·자료 출처를 검사한다. 선택적 CCTV 영상은 보조 근거다.
- **분석:** 위험규칙과 예열 모델이 구역별 위험도·예열 필요성을 계산한다. 합성 또는 mock 데이터는 안전결정의 실측 근거로 취급하지 않는다.
- **가열:** 전용 제어기의 현장 안전인터록을 우회하지 않는 방식으로 요청하고 출력 피드백을 확인한다.
- **안내:** 열선 ON과 노면 개선을 혼동하지 않으며, 위험이 남으면 안내를 유지한다.
- **조치 확인:** 노면 온도·상태와 전력사용 변화를 추적하고 운영자에게 재결빙·센서 고장·가열 실패를 알린다.
- **사후 평가:** 위험 노출시간, 소비전력, 장치 가동·장애, 현장 점검 결과를 비교한다.

**중앙 통신 두절 시에는** 기존 로컬 안전 인터록과 수동 대응절차가 우선한다. Edge의 신규 완전자율 가열결정은 현 시점에서 미완성으로 표시하며, 이 기능이 없는 상태에서 완전 무인·무정지 운전을 약속하지 않는다.

**실증 장소 명칭은 미확정**으로 유지한다. 접근로 위치·시설 운영자·전력/인허가 정보를 확보하기 전에 실제 특정 시설에 도입이 가능하다고 주장하지 않는다.

## 사업 담당 창구 가설

- **천안시 해당 공공시설 관리부서:** 위치 승인, 공사·시설 이용자 안내, 운영책임.
- **천안시 도로관리 부서:** 이후 ROAD 제품 확장 협의처. ACCESS 실증의 필수 관계기관으로 가정하지 않는다.
- **시설 전기 관리자 및 적격 시공사:** 발열체·배전·안전검사, 시험구간 구축.
- **에스엘티:** 정보통신공사 범위의 CCTV·전광판·통신 및 고객창구.

**실제 기상 이벤트가 발생하지 않으면 성과검증을 다음 겨울로 연장할 수 있다.** 눈이 오지 않은 현장에서 사고 감소·결빙 제거 효과를 성과로 선언하지 않는다.

### 필수 게이트

- HIL: 출력실패, 과열·누전, stale 센서, 영상불량, 중앙망 단절, 명령 중복·만료를 검증.
- 전광판: 예열 명령·ACK·물리 가열·노면 위험완화 상태가 올바르게 다르게 표출되는지 검증.
- 계측: 교정된 노면온도·습윤 센서, 비교구역, 실제 에너지 계량.
- 운영: 점검 담당자·수동조치·고장 대응시간과 안전공지 책임 확정.

| 반응시간 | 위험 이벤트→실제 물리출력 피드백, 별도로 경고 표출 ACK | 명령 API 성공만으로 완료 인정 금지 |
| 발열 시효성 | 위험도 예측 vs 예열 개시·위험완화 관측 | 현장 조건/센서 오차 고려 |
| 전력 효율 | 단위 면적·위험일·기상조건별 kWh | 타사 대비 절감율 사전 보장 금지 |
| 경고 전달률 | 승인 문구 표출 명령 대비 실제 플레이어·장치 피드백 | 실출력 확인 방식을 먼저 구현 |
| 고장/수동 개입 | 안전정지, 센서 오류, 운영자 조치시간 | 숨겨진 mock/추정 데이터 배제 |
| 접근로 이용성 | 겨울철 우회·불편·민원 기록과 현장 설문 | 미끄럼 사고 감소의 직접 인과 주장 자제 |

**권장 시험설계:** 동일 시설의 가열구역·비가열 비교구역을 가능한 범위에서 계측하고, 기온·강수·일사·그늘·유동량 차이를 보정한다. 보행자에게 위험한 비교구역을 방치하는 시험은 시행하지 않는다. 비교구역은 안전한 비이용 시험구간 또는 기존 방식이 유지되는 구간에서 설계한다.

# 10. 제안의 기술적·사업적 차별성과 확장

**다른 융설 관제와 다른 점은 '예열 최적화' 자체가 아니다.** EcowayVision에 이미 관련 기능이 존재하고 유사 시장제품도 있다. 에스엘티가 공급할 차별화는 다음의 조합이다.

1. **사용자 접점 안전정보:** 실제 위험/가열/고장 상태를 시민이 보기 쉬운 사전 승인 메시지로 제공한다.
2. **검증 중심 운영:** AI 판단과 실제 출력·노면 계측·표출장치 동작의 증거를 분리한다.
3. **관리주체 단순화:** 보행접근로 한 곳에서 출발해 반복 설치 가능한 표준 제품으로 발전한다.
4. **기존 소프트웨어 재사용:** EcowayVision 지도·AI·NOC·보전·에너지 기능을 새로 만들지 않아 비용을 집중할 수 있다.

확장 순서는 `SafeSurface ACCESS` → 시내 시설 다중관리 `FLEET` → 일반도로 `ROAD`다. ROAD는 별도 도로관리청·교통안전시설 승인, 도로 구조·제설 및 도로전광표지 기준 검증 후 별도 발주로 진행한다.

# 11. 천안시에 요청할 결정

첫 면담에서 대규모 장비 납품 계약을 요청하지 않는다. **① 미끄럼 민원·결빙이 확인된 시설 접근로 후보 1~2곳 ② 시설별 전기/공사 담당자 협의 ③ 겨울 HIL·현장 실증을 위한 데이터 수집 허가 여부**를 협의한다.

**도입 판단표:** 실제 위험과 시민 편익이 확인되는가 / 설치 적법성·전력·마찰이 적합한가 / HIL 안전 게이트를 통과했는가 / 실증사업 예산 및 관리 책임자가 정해졌는가. 미충족이면 공공도로 확장과 납품을 보류한다.
